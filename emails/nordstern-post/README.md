# Nordstern Post ist in die Club Suite umgezogen

Vorlagen, September-Ausgabe, unverändertes Versandarchiv, Resend-Metadaten und Sponsoren-Auswahl werden seit dem 24.09.2026 im Schwesterprojekt `bsv-socialmedia` gepflegt:

- `../bsv-socialmedia/emails/nordstern-post/` – HTML, Text, Versandarchiv und Dokumentation
- `../bsv-socialmedia/docs/newsletter.md` – Konzept und Redaktionsablauf
- `../bsv-socialmedia/scripts/newsletter-sponsors.mjs` – Sponsoren-Auswahl

In der Club Suite: **Redaktion → Newsletter**. Newsletter haben dort eine eigene E-Mail-Vorschau und einen HTML-/Text-Export. Die öffentlichen Bilder und Sponsorlogos bleiben auf dieser Website erreichbar. Mitgliedschaftsformular und Newsletter-Einwilligung bleiben ebenfalls Teil der Website.
