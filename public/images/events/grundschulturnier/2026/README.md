# GST 2026 Bildergalerie

Weboptimierte Bilder für das Zeller Grundschulturnier 2026 in diesem Ordner ablegen.

Die Seite `/erlebnis/buergerstiftung-grundschulturnier` liest unterstützte Bilddateien (`avif`, `gif`, `jpg`, `jpeg`, `png`, `webp`) beim Astro-Build automatisch ein. Dateinamen werden numerisch sortiert.

Für weitere Jahre einfach einen parallelen Jahresordner anlegen, zum Beispiel `../2025/`. Das Jahr erscheint dann automatisch als eigener Galerie-Tab.
